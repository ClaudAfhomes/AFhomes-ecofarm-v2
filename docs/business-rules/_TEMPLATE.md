# Rule Template (normative)

Copy this template for every rule. Keep every field — write `UNKNOWN`, `NOT DOCUMENTED`, or `NOT VERIFIED` instead of omitting one.

### BR-XXX-NN — Short descriptive name

- **Documentation status:** SOURCE_DOCUMENTED / CODE_OBSERVED / PARTIAL / MISMATCH / SOURCE_CONFLICT / SOURCE_MISSING / SUPERSEDED / OUT_OF_SCOPE
- **Implementation status:** NOT_ASSESSED / NOT_IMPLEMENTED / PARTIAL / MISMATCH / IMPLEMENTED_UNVERIFIED / TEST_VERIFIED
- **Source document:** Exact filename and version/build
- **Source location:** Exact sheet and cells, formula, section/page, or function/procedure
- **Source authority:** Only what the source establishes; otherwise UNKNOWN
- **Original rule:** Faithful transcription or concise source-grounded summary
- **Rule explanation:** Plain-language Taglish explanation
- **Formula or calculation:** Exact documented formula, including rounding, boundaries, and examples if available
- **Inputs:** Required data
- **Outputs:** Expected result or record changes
- **Conditions:** When the rule applies
- **Exceptions:** Documented exceptions and restrictions
- **Effective dates:** Exact dates and cutover behavior if documented
- **People and permissions:** Relevant roles and authorized actions
- **Workflow:** Before, during, and after the rule is applied
- **Current code behavior:** Verified paths and line references, or NOT VERIFIED
- **Gap analysis:** Match, mismatch, partial implementation, or not located
- **Related tests:** Actual test files and test cases, including whether they were run
- **Dependencies:** Related rules and required data
- **Open questions:** Only genuinely missing or conflicting information
- **History:** Relevant `CHANGELOG.md` entries
